# Repository instructions

- Whenever updating this project, also update the `最終更新 / Last updated` date and time near the top of `README.md` in the same commit.
- Use the current date and time in the `Asia/Tokyo` time zone, formatted as `YYYY-MM-DD HH:MM (JST)` (24-hour clock).
- When changing resume facts, check both language versions of the website for consistency.
- Keep private application documents out of the repository. Do not add resume PDFs or resume Markdown files to this repository. The website must use anonymized company names and omit personal contact details, date of birth, salary, residence expiry, family details, and the application photo.
