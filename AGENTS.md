# Repository instructions

- Whenever updating this project, also update the `最終更新 / Last updated` date near the top of `README.md` in the same commit.
- Use the current calendar date in the `Asia/Tokyo` time zone, formatted as `YYYY-MM-DD (JST)`.
- When changing resume facts, check both language versions of the website and the public Markdown/PDF documents in `docs/resume/` for consistency.
- Keep private application documents out of the repository. Public resumes must use anonymized company names (as on the website) and omit personal contact details, date of birth, salary, residence expiry, family details, and the application photo.
