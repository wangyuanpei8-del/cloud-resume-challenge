業務経験・資格・個人開発の内容を日英文サイトと揃えた公開版です。履歴書は個人情報を省いて作成しています。会社名は匿名にしています。住所、電話番号、メールアドレス、生年月日、年収、在留期限、家族情報、写真を含む選考提出用の完全版は公開しません。

These public documents summarize the same experience, qualifications, and project as the bilingual website. Private application documents containing contact, financial, or residence details are kept separately.

経歴・資格・プロジェクト実績を更新する際は、MarkdownとPDF、日英文ページ、リポジトリのREADMEを併せて確認します。学習中の資格と取得済みの資格、業務経験と個人開発は区別して記載します。
