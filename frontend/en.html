I built this bilingual site on AWS to extend my operations experience into building and automation. I used generative AI as a learning aid and carried out the configuration, implementation, and deployment myself.

What I built

  • Static content delivery with S3 and CloudFront, using OAC to restrict access to S3
  • An access counter using API Gateway, Lambda, and DynamoDB
  • GitHub Actions workflows for frontend delivery and Lambda updates after passing tests

Design and validation

  • Managed services to reduce server maintenance
  • Atomic DynamoDB increments to avoid overwrites from read-then-write updates
  • Four pytest and Moto tests: response format, initial value, repeated increments, and persisted data

Unit tests mock DynamoDB; they do not validate live IAM, CORS, or delivery configuration. The counter increments on successful API requests and does not represent unique visitors.

Planned improvements: infrastructure as code, monitoring, and recovery procedures.
