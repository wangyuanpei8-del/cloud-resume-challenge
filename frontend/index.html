サーバーレス構成の職務経歴サイト

業務での運用経験を構築・自動化につなげるため、この日英対応サイトをAWS上に構築しました。生成AIを学習支援として活用し、自分で設定・実装・デプロイを行った個人プロジェクトです。

構築・実装したこと

  • S3・CloudFrontによる静的コンテンツ配信と、OACによるS3へのアクセス制限
  • API Gateway・Lambda・DynamoDBによるアクセスカウンター
  • GitHub Actionsによるフロントエンド配信と、テスト成功後のLambda更新

設計と検証のポイント

  • サーバー管理の負担を抑えるため、マネージドサービスを採用
  • DynamoDBの原子的な加算で、読み取り後の上書きによる更新競合を回避
  • pytest・Motoでレスポンス、初回値、連続加算、保存結果の4項目を検証

単体テストはDynamoDBをモック化しています。実際のIAM・CORS・配信設定の検証とは別です。カウンターはAPIの成功リクエストを加算するもので、ユニーク訪問者数ではありません。

今後の改善：インフラのコード化（IaC）、監視・復旧手順の整備。
